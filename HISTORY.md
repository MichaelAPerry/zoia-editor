# History and credits

This editor was developed in a private project. The pedal-style restyle (black enclosure, lit button grid, OLED display, knob, stompswitches) was made as part of the move.

The code was written by AI coding agents (Codex and Claude Sonnet) under review by Claude Opus, for Michael Perry.

## Credits

- [zoia_lib](https://github.com/meanmedianmoge/zoia_lib) by meanmedianmoge, GPL-3.0: the binary patch format documentation, the module index (`ModuleIndex.json`) that the editor's module catalogue and simulator layout metadata derive from.
- djigneo / apparent1: decoding of the patch format.
- Sranderley: encoding of the patch format.
- eimerreis/zoia-editor and darosh/zoian were studied for ideas about the format.

ZOIA is a product of its manufacturer. This project is unofficial and unaffiliated.
